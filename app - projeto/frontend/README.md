# Frontend

Aplicacao React principal do projeto ABP.

## Como rodar

```bash
npm install
npm run dev
```

## Estrutura

```text
src/
  App.tsx               # carrega a Home como pagina principal
  main.tsx              # entrada do React
  pages/Home.tsx        # pagina Home projeto ABP
  components/Chatbot.tsx
  data/menus.ts         # arvore de atendimento do chatbot
  types/index.ts        # tipos compartilhados
  assets/img/           # imagens usadas pelos componentes
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
